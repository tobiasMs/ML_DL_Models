13. Suggested Journal Method Description
----------------------------------------
This study performed binary classification of tomato leaf images into diseased and healthy classes. The dataset consisted of 6000 images, with 3000 diseased images and 3000 healthy images. A stratified train-validation split was applied with an 80:20 ratio, resulting in 4800 training images and 1200 validation images. The validation set contained 600 diseased and 600 healthy images. Images were resized to 300 x 300 pixels, decoded in RGB format, converted to tf.float32, and processed using a TensorFlow data pipeline with shuffling, batching, and prefetching.

Data augmentation was applied only to the training pipeline using random horizontal flipping, random rotation, random zoom, and random contrast adjustment. The model used ResNet50 pretrained on ImageNet as a frozen feature extractor with include_top=False. The extracted feature maps were reduced using GlobalAveragePooling2D and classified using a lightweight classifier head consisting of Dense(128, ReLU), Dropout(0.5), Dense(64, ReLU), Dropout(0.4), and Dense(1, Sigmoid). Fine-tuning was disabled so that the pretrained backbone remained frozen during training. The model was optimized using SGD with a learning rate of 0.001 and momentum of 0.8. Binary cross-entropy with label smoothing of 0.2 was used as the loss function. Model performance was evaluated using accuracy, precision, recall, F1-score, AUC, and confusion matrix analysis.

14. Important Methodological Note
---------------------------------
The current ResNet50 experiment intentionally disabled fine-tuning and froze the backbone. This design makes the model less aggressive than a fully fine-tuned transfer learning configuration. The reported performance therefore represents the capability of ResNet50 as a fixed feature extractor combined with a lightweight classifier head. If higher accuracy is required, a second training phase can be added by unfreezing selected upper layers of the ResNet50 backbone and training them with a smaller learning rate.
